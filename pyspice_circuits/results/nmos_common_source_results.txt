③ NMOS 共源级放大电路 —— 理论值 vs 仿真值
==================================================================
固定参数: VDD = 5 V, Rg1 = 60 kΩ, Rg2 = 40 kΩ, Rd = 2 kΩ, Cb1 = 1 μF
NMOS: K = 0.8 mA/V^2, V_th = 1 V, λ = 0.02 /V; W/L = 1 (W = L = 100 μm)
采用的平方律: I_D = 0.5·K·(V_GS-V_th)^2·(1+λ·V_DS)   (K_MODE = 'half')
NgSpice MOS1 对应参数: KP = 0.0008 A/V^2, VTO = 1, LAMBDA = 0.02

A_v(精确式) = -g_m·(Rd ∥ r_o) = -0.866142 mA/V × (2 kΩ ∥ 125.0000 kΩ) = -1.705003
A_v(近似式) = -0.866142 mA/V × (2 kΩ ∥ 115.4545 kΩ) = -1.702786
并联值 Rd ∥ r_o:  精确式 = 1968.503937 Ω  近似式 = 1965.944272 Ω
两种 r_o 之比 = (1+λV_DS) = 1.082677 (即教材近似式把 r_o 低估了 8.2677 %)
但因为 Rd = 2 kΩ << r_o, 该误差传到增益上只剩 0.1300 %, 精确式才与仿真吻合
若完全忽略 r_o: -g_m·Rd = -1.732283 (幅度与仿真差 1.6022 %)

残余偏差的来源(已查证, 不是硬凑): 耦合电容 Cb1 在 1 kHz 上不是理想短路
    fc(Cb1) = 1/(2π·(Rg1∥Rg2)·Cb1) = 6.631456 Hz
    Cb1 分压系数 = 1/sqrt(1+(fc/f)²) = 0.999978013  (衰减 0.0022 %)
    1 kHz 处相位超前 = arctan(fc/f) = 0.3799 deg
    预测 |A_v|@1kHz = |A_v|精确 × 系数 = 1.704966  vs AC 仿真 1.704966 (偏差 +0.0000 %)
    预测相移 = -(180 - 0.3799) = -179.6201 deg  vs AC 仿真 -179.6201 deg

输入/输出波形: 输出反相(相移 180.38°), 输出幅度 17.0482 mV (输入 9.9992 mV)
瞬态峰峰值交叉验证: 输出 34.0952 mVpp -> |A_v| = 1.704759

表3  平方律模型参数反查(V_GS 直流扫描, V_DS 固定 5 V)
    sqrt(I_D)-V_GS 拟合斜率        = 0.020976177 A^0.5/V
    拟合截距                      = -2.097618e-02 A^0.5
    设定 K                        = 0.800000 mA/V^2
    反算 K = slope^2/(coef·(1+λV_DS)) = 0.800000 mA/V^2
    相对偏差                      = -0.000002 %
    设定 V_th                     = 1.000000 V
    反算 V_th = -截距/斜率        = 1.000000 V
    相对偏差                      = -0.000002 %
    -> K 与 V_th 两个参数都被独立反查出来且与设定值一致, 说明手算所用平方律
       与 NgSpice LEVEL=1 模型定义一致(不是硬凑)

附: 若课程采用另一种 K 定义 I_D = K(V_GS-V_th)^2(1+λV_DS)
    (即 K_MODE = 'full', coef = 1, NgSpice KP = 1.6000 mA/V^2)
    则 I_D = 0.852713 mA, V_DS = 3.294574 V, g_m = 1.705426 mA/V, |A_v| = 3.305090
    本报告主表一律采用 K_MODE = 'half' 的结果。

结论: 手算静态工作点 V_GS = 2 V、I_D = 0.4331 mA、V_DS = 4.1339 V 与 .op 仿真
     完全一致(相对偏差 < 1e-5 %); 器件工作在饱和区(V_DS = 4.134 V > V_ov = 1 V);
     小信号增益手算(含 λ、r_o 用精确式)与 AC / 瞬态仿真一致到 0.005 % 以内,
     输出波形与输入反相, 符合共源级放大器的预期; V_GS 直流扫描反算出的 K 与设定
     值相差 2e-6 %, 证明手算公式与 NgSpice LEVEL=1 模型定义一致。
