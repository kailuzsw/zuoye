贪吃蛇游戏 · 项目说明书

大一考核项目，做了一个贪吃蛇游戏，包含手动玩、AI自动演示、主题切换、计分统计。

一、项目做了什么

一个双击 .html 就能在浏览器打开的贪吃蛇游戏。

- 手动模式：键盘方向键控制，撞墙或撞自己就结束
- AI演示：点一下按钮，蛇自己去找食物吃，连续吃掉15个不死
- 主题切换：深色/浅色一键换，刷新后自动记住
- 计分统计：显示当前得分、最高分、玩了多少局
- 重置按钮：清空所有统计数据


二、Git相关概念（大白话）

- 分支：相当于开一个新存档，改坏了也不影响主存档

五、AI给过的错误信息

1. 蛇可以穿墙
AI说蛇可以从左边穿到右边，查证后正确规则是撞墙即死，代码里保留的是撞墙结束。

2. 主题切换不影响游戏
加了主题切换后游戏本身动不了了，只有主题能切。排查后发现是多个功能变量冲突，重新梳理加载顺序才修好。

3. AI演示会计局数
AI生成的代码里，AI演示也会增加总局数。后来改成了AI演示不计入历史记录。


六、AI代码的关键逻辑

吃到食物变长：
蛇头碰到食物时，食物消失、得分+1、蛇身增加一节。

AI寻路：
每步计算蛇头到食物的方向，优先走能靠近食物的安全方向，不行就换一个。

空格计局规则：
只有真正玩过（得分>0或已结束）按空格才加局数，刚打开按空格只刷新食物。


七、代码分工

- 游戏核心逻辑（移动、碰撞、食物、得分）：AI生成
- AI自动寻路：AI生成
- 主题切换：AI生成
- 计分统计：AI生成
- 修复主题切换冲突：自己改
- 修复AI计局数问题：自己改
- 修复空格误增局数：自己改


八、阶段一：手动版

怎么做的：
把需求发给AI，生成HTML代码，保存双击就能玩。

怎么验证的：
手动玩了5局，确认移动、吃食物、撞墙结束、得分显示都正常。


九、阶段二：AI演示

怎么做的：
让AI在代码里加AI演示按钮和自动寻路逻辑。

怎么验证的：
点AI演示，蛇连续吃掉15个食物没死，全程不用人操作。
